# aube bug reproductions

Minimal test cases for bugs found migrating a large monorepo from pnpm to aube.
Each directory is self-contained: `cd` into it and run the commands in its README.

GitHub Actions workflows run each repro on push, comparing aube's behavior against pnpm.

## Fixed in beta.10

1. **`alias-override-conflict/`** — _Fixed in beta.10._ `npm:` alias replaced by an
   unrelated `pnpm.overrides` entry.

2. **`overrides-not-read-from-workspace/`** — _Fixed in beta.10._ `overrides` in
   `pnpm-workspace.yaml` ignored by `--frozen-lockfile`.

3. **`pnpm-lockfile-host-only-platforms/`** — _Fixed in beta.10._ `pnpm-lock.yaml`
   generated by aube only contained optional deps for the host platform.

## Fixed in beta.12

4. **`filter-skips-root-deps/`** — _Fixed in beta.12._ `--filter` skipped root
   workspace `devDependencies`.

## Fixed in 1.1.0

5. **`frozen-lockfile-catalog-override/`** — _Fixed in 1.1.0._ `--frozen-lockfile`
   rejected `catalog:` references in overrides.

## Open bugs (as of 1.2.1)

6. **`workspace-bin-not-linked/`** — Workspace package bins not linked into
   dependent packages' `node_modules/.bin/`. When package A declares
   `"bin": {"my-tool": ...}` and package B depends on A via `workspace:*`,
   pnpm links `my-tool` into B's `.bin/`. aube does not. Blocks any monorepo
   that uses shared tooling bins across workspace packages.

7. **`frozen-lockfile-override-specifier/`** — `--frozen-lockfile` rejects
   specifiers changed by overrides. When an override rewrites `plist@^3.0.4`
   to `>=3.0.5`, pnpm records `>=3.0.5` in the lockfile and accepts it. aube
   compares the original manifest specifier against the lockfile and fails.

8. **`exotic-git-dep-resolution/`** — Git URL dependencies fail to resolve.
   `@electron/rebuild` depends on `@electron/node-gyp` via a git URL. pnpm
   resolves it; aube fails with "exotic specifier blocked by blockExoticSubdeps".
